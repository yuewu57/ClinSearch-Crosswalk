# Historical reference artefacts

This directory preserves historical standalone reference material used during development and conformance work.

- `cochrane_data_pubmed_converter_v20_cli_v2_YW_16082026.py` is retained as a historical v20 standalone executable snapshot.
- The maintained package under `src/ovid_pubmed_converter/` is the current executable reference implementation.
- The normative rule definition for the current software is the maintained v20 base specification plus the approved v21 delta under `docs/`.

Files in this directory are archival references and should not be used as the public entry point for current conversion.
